# Log

Format — 3 lines per day, written at the END of the session:

```
## YYYY-MM-DD (phase 0, day N)
did:   what actually got done
stuck: current blocker (or "-")
next:  the exact first task for tomorrow's session
```

Weekly review — every Sunday, 20 min:

```
### Week N review
building vs reading ratio: ok / drifting to reading
phase deadline realistic:  yes / slipping (why)
one fix for next week:     ...
```
